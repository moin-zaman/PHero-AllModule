Problem 4  -->

?? কে বলে Nullish Coalescing Operator

এর মানে হলো  যদি a null বা undefined হয়, তাহলে b return করবে।
অন্যথায় a return করবে।

const x = null ?? 5;      // 5 (কারণ x null ছিলো)
const y = undefined ?? 10; // 10 (কারণ y undefined ছিলো)
const z = 0 ?? 7;          // 0 (কারণ 0 null/undefined না)
const w = "" ?? "Hello";   // "" (কারণ empty string null/undefined না)


difference between || (Or Operator  && Nullish Coalescing Operator)

const a = 0;

console.log(a || 100); // 100 (কারণ 0 falsy)
console.log(a ?? 100); // 0   (কারণ 0 null/undefined না)

তাই, যদি শুধু null/undefined হলে fallback চাই, তখন ?? ব্যবহার করা উচিত।
আর যদি falsy value (0, "", false) পেলেই fallback চাই, তখন || ব্যবহার করা হয়।

১) API response handling: weather বা any API থেকে data আসার সময় nested property safe ভাবে access করার জন্য ব্যবহার করা হয়, যেমন response?.data?.current?.temp যাতে missing data থাকলেও app crash না করে।

২) User profile system: login থাকা বা না থাকা user এর ক্ষেত্রে user?.profile?.name ব্যবহার করে safely username পাওয়া যায়, যাতে guest user হলেও error না আসে।

৩) E-commerce product page: product data incomplete হলে যেমন discount বা pricing missing থাকলে product?.details?.pricing?.discountPrice দিয়ে safe access করা হয়।

৪) Notification system: email বা user data থেকে info নিতে গেলে notification?.user?.email ব্যবহার করা হয় যাতে background job বা notification service crash না করে।

৫) Config / settings system: app settings সবসময় present নাও থাকতে পারে, তাই config?.ui?.theme দিয়ে optional configuration safely access করা হয়।

৬) Dashboard / analytics: report বা stats data missing হতে পারে, তাই stats?.monthly?.revenue ব্যবহার করে safe ভাবে data পড়া হয় যাতে dashboard break না হয়।
